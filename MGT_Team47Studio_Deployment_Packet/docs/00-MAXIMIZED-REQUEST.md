# 00 Maximized request

Version 1.0.0, 2026-11-14. This is the request the packet was built against.

## Objective

Build a Python-based, end-to-end deployment and operations packet that sits on top of the existing Team 47 Studio web and app build, improves results without changing the stack, and is exported to GitHub and Google Drive in a new folder, `MGT_Team47Studio Deployment Packet`.

## Assess first

All GitHub repositories (the named one, `MGT-Skin-Care-ChatGPT-Web-Portal-Build-V2.5`, is the system of record), the Drive record (production diagnostic, checkpoints, AI activation notes, marketing playbook, outreach packet, tracker), the live site, the repository's own gate scripts, and the local workstation.

## Constraints

1. Keep the stack: Next.js web, Express API, Expo mobile, Supabase, Stripe, Cloud Run behind Cloudflare, the TypeScript AI gateway and FastAPI broker, Ollama local-first.
2. Change a model only when an open-weight alternative measurably beats the incumbent on the same cases. Changes are proposed, never applied.
3. Honor the holds already on record: release decision HOLD, subscriptions off, agents draft-only with human review, no automatic sending, posting or scraping, local Ollama never exposed, no secrets in Git, Drive or chat.
4. Cosmetic-guidance positioning. No outcome guarantees.
5. Economy first. Every cost is sourced or flagged.

## Deliverables

1. Assessment of the current build.
2. Python package and CLI.
3. Deployment strategy and connection setup for Web Portal, Android, Google Play and iOS.
4. AI operations: OpenClaw through Ollama as the primary driver of chat bots and marketing agents.
5. Go-to-market campaign, premium customer care, partner relationship management, retention, and the value and result proposition.
6. ROI model: monthly cost against subscriber growth.
7. One consolidated list of owner decisions.

## Interpretations stated up front

- "Run on local hardware, with cloud backup": the workstation is the primary AI and agent plane. The cloud stays the public web and API runtime, the metered AI fallback, and the home of encrypted backups. The workstation does not serve public traffic; the repository's own documents rule that out.
- "Prod ready to ship": the packet prepares, verifies and tracks. The 2026-11-13 diagnostic says HOLD. The packet does not override it.
- "Open wight" is read as open-weight; "Profession AI" as professional.
- The GitHub repository is public. Code and technical documents go there. Economics, go-to-market and partner material go to Drive only.

# v2.50 backup-policy admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production API and worker startup now require exact decimal backup freshness and restore-rehearsal limits. Backup age is bounded to 1–72 hours and restore evidence to 1–365 days. Missing, fractional, scientific-notation, and out-of-range values fail before database construction instead of being defaulted or clamped by worker execution.

Deployment preflight uses the same boundaries. Live backup completion, immutable storage, checksum verification, and successful restoration remain target-environment evidence.

# v2.51 accessibility-evidence admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production API and worker startup now require a credential-free HTTPS accessibility evidence location and a canonical UTC validation timestamp that is not in the future. Missing, ambiguous, credential-bearing, non-HTTPS, or future-dated evidence fails before database construction.

This validates evidence shape and timing only. Deployed keyboard, screen-reader, zoom/reflow, browser, device, and human WCAG review remain external release evidence.

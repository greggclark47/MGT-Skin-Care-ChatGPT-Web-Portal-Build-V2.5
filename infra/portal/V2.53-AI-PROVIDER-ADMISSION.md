# v2.53 AI-provider admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production startup now requires exact enabled/disabled declarations for Ollama and OpenClaw. Enabled providers require credential-free, non-placeholder service URLs; OpenClaw also requires an explicit supported API mode, with an injected non-placeholder key for compatibility mode. Optional hosted OpenAI escalation rejects placeholder references when configured.

Invalid provider settings fail before database construction. Live model availability, account access, provider billing, output quality, and hosted/local failover remain target-environment evidence.

# v2.55 immutable-image admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production API and worker startup now independently require the Node, API, web, Ollama, and Caddy images to use exact lowercase SHA-256 digest references. Mutable tags, truncated digests, uppercase digests, URL-shaped references, and absent declarations fail before database construction.

Deployment preflight and direct-process admission use the same accepted form. Registry access, image-signature verification, vulnerability posture, and live digest pull evidence remain target-environment release gates.

# v2.56 database-target admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production database admission now requires exactly one non-empty database path segment and rejects URL fragments, in addition to the existing verified-TLS and target-override protections. A syntactically valid connection URL can no longer omit the reviewed database, introduce an ambiguous nested target, or append an ignored fragment.

Preflight and API/worker startup apply the same rule before database construction. Live database identity, credentials, connectivity, migration lineage, row-level security, and restore evidence remain external release gates.

# v2.57 identity-origin admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

The production Supabase location must now be one exact credential-free HTTPS origin. Paths, query strings, fragments, explicit non-default ports, and non-canonical origin forms are rejected before API or worker database construction.

This prevents configuration layers from interpreting different identity tenants or routes from the same nominal service declaration. Live tenant ownership, key validity, role permissions, deletion behavior, and provider audit evidence remain external release gates.

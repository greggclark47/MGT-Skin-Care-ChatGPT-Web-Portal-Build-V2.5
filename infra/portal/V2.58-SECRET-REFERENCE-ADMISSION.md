# v2.58 secret-reference admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production identity, operations-alert, customer-notification, OpenClaw, and optional OpenAI secret references now reject surrounding whitespace, control characters, placeholder text, empty values, and values beyond the bounded injection limit. Validation failures remain generic and do not serialize the submitted reference.

Preflight and direct API/worker startup enforce the same boundary before database construction. This validates injection shape only; secret-manager provenance, rotation, revocation, provider acceptance, and live least-privilege evidence remain external release gates.

# v2.60 deployment-mode admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production preflight now requires `DEMO_MODE` to be exactly the lowercase string `false`, matching direct API runtime admission. Case variants, booleans, missing values, and truthy or numeric-looking substitutes fail closed.

This removes a preflight/runtime interpretation gap. It does not prove that the deployed environment is the approved production target; target identity and live orchestration evidence remain separate release gates.

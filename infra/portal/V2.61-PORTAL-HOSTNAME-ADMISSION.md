# v2.61 portal-hostname admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production portal admission now requires a canonical lowercase DNS hostname with valid bounded labels. Raw IP addresses, uppercase forms, underscores, empty labels, leading or trailing hyphens, trailing dots, schemes, and paths fail closed before application construction.

The exact HTTPS public origin must still match this hostname. Live DNS control, certificate issuance, edge routing, domain renewal, and failover observations remain external release evidence.

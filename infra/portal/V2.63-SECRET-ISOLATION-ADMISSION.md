# v2.63 secret-isolation admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production startup now requires distinct injected secret references for identity roles, operations alerts, customer notifications, enabled AI providers, optional hosted AI, and enabled billing. Reusing one accepted reference across integration roles fails before database construction.

This enforces configuration-level credential compartmentalization without serializing secret values. Live secret-manager identity, least privilege, rotation, revocation, and provider-side authorization remain external release evidence.

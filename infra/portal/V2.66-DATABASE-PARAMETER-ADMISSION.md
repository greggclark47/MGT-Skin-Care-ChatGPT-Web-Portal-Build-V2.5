# v2.66 database-parameter admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production PostgreSQL URLs now permit exactly one query parameter: `sslmode=verify-full`. Session options, application-name overrides, target overrides, duplicate TLS modes, and every other driver parameter fail before database construction.

This binds runtime behavior to the reviewed database target instead of trusting driver-specific query interpretation. Live credentials, target identity, schema lineage, row-level security, connectivity, and restore evidence remain external release gates.

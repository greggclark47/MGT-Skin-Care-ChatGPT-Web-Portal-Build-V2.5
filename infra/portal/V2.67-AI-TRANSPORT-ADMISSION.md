# v2.67 AI-transport admission checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Plain HTTP AI endpoints are now limited to canonical single-label service names intended for private container or cluster networks. Dotted hostnames, raw IP addresses, localhost placeholders, and malformed names require rejection; externally addressed Ollama and OpenClaw services must use HTTPS.

This prevents an internal-transport exception from silently covering a public or ambiguous target. Live network segmentation, service identity, TLS verification, and provider behavior remain external release evidence.

# v2.68 disabled-feature residue checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production startup now rejects active configuration retained behind disabled customer-webhook, Ollama, OpenClaw, or subscription features. Dormant endpoints, credentials, modes, product identifiers, and webhook settings must be removed rather than merely hidden by a feature flag.

This reduces accidental reactivation and stale-secret exposure. Historical evidence may still reference earlier configurations, but live environment declarations must represent only enabled scope. Provider-side revocation and secret-manager cleanup remain external operational evidence.

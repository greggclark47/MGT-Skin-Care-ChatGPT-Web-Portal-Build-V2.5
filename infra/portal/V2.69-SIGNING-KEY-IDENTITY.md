# v2.69 signing-key identity checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production operations-alert and enabled customer-notification webhooks now require explicit bounded signing-key identifiers. A token without a valid key ID, or an empty, malformed, or missing ID, fails before database construction.

The identifier supports receiver verification, audit correlation, and controlled key rotation without exposing the signing secret. Live key-manager provenance, rotation execution, receiver trust stores, and revocation evidence remain external release gates.

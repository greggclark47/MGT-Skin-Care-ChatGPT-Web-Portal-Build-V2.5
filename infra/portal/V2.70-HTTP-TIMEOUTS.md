# v2.70 HTTP-timeout checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

The production API server now applies explicit 30-second request, 15-second header, and 5-second keep-alive timeouts. Direct process startup no longer inherits changing Node defaults for these denial-of-service and resource-retention boundaries.

Non-production servers retain framework defaults. Live edge-proxy alignment, load behavior, upstream timeout ordering, and target-environment observations remain external release evidence.

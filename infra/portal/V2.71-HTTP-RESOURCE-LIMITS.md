# v2.71 HTTP-resource-limits checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

The production API now caps each socket at 1,000 requests, each request at 100 headers, and the process at 1,000 concurrent connections. These ceilings are applied directly to the Node HTTP server after listener creation.

Live capacity testing, edge connection limits, autoscaling, and target-specific sizing remain external release evidence.

# v2.72 proxy-and-query boundary checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production Express startup now explicitly disables proxy trust and selects the simple query parser. Untrusted forwarding headers cannot redefine the client address, protocol, or host, and bracketed query input cannot create nested attacker-controlled object shapes.

Any future trusted-proxy deployment requires a separately reviewed, exact proxy policy. Live edge topology and forwarding-header behavior remain external release evidence.

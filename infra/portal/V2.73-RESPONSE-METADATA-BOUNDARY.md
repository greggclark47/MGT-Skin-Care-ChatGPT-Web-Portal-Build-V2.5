# v2.73 response-metadata boundary checkpoint

Review date: 2026-10-12. Accountable owner: Gregg Clark of MGT.

Production Express startup now disables entity-tag generation and enables JSON escaping. Sensitive `no-store` API responses no longer emit reusable validators, and JSON output escapes HTML-significant characters when a downstream consumer embeds it incorrectly.

These process-level controls complement existing response headers. Live CDN behavior, edge header preservation, browser observations, and penetration testing remain external release evidence.

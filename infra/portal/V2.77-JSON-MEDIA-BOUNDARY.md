# v2.77 JSON-media boundary checkpoint

Requests with bodies on `POST`, `PUT`, or `PATCH` under `/api/hub` and `/api/v1` must declare `application/json` or a structured `application/*+json` media type. The check runs before JSON parsing and does not affect empty mutation requests or read-only methods.

Rejected payloads receive a sanitized `415 unsupported_media_type` response. Subscription webhooks retain their dedicated raw-body verification path and are mounted before this boundary.

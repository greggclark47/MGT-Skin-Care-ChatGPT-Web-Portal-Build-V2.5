# v2.89 database pool-error boundary checkpoint

The PostgreSQL pool now owns its background `error` event. Idle-client failures are recorded as `database_pool_error` with only a strictly allowlisted PostgreSQL/transport error code.

Raw driver messages, SQL, connection strings, credentials, hosts, client objects, and stack traces are not serialized. Invalid or unexpected codes collapse to `database_pool_error`.
